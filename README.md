# QueVesVe!&

Frontend de **QueVesVe!&**, una plataforma de videos cortos construida con React Native y Expo.

## Technologies

- [Expo](https://expo.io/)
- [React Native](https://reactnative.dev/)
- [React Navigation](https://reactnavigation.org/)
- [styled-components](https://www.styled-components.com/)
- [expo-av](https://docs.expo.io/versions/latest/sdk/av/)
- [expo-camera](https://docs.expo.io/versions/latest/sdk/camera/)
- [@expo/vector-icons](https://expo.github.io/vector-icons/)
- [expo-linear-gradient](https://docs.expo.io/versions/latest/sdk/linear-gradient/)
- [lottie-react-native](https://docs.expo.io/versions/latest/sdk/lottie/)

## How To Use

Requirements: [Node.js](https://nodejs.org/) + [Expo CLI](https://expo.io/tools)

```bash
# Install dependencies
$ npm install

# Run the app (Android)
$ npm run android

# Run the app (iOS)
$ npm run ios
```
